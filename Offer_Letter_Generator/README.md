# Offer Letter Generator

A real-time offer letter generator built with 
pure HTML, CSS and JavaScript.

## Features
- Live preview as you type
- Color theme switcher
- Print / Save as PDF
- No frameworks, no libraries

## Tech Used
- HTML5
- CSS3 (Grid, Variables)
- Vanilla JavaScript (DOM)
